# Security Policy

## Supported versions

Security fixes are provided for the latest release on the `main` branch.

## Reporting a vulnerability

Please report security issues privately:

1. Open a **GitHub Security Advisory** on [chayprabs/drive-md-editor](https://github.com/chayprabs/drive-md-editor/security/advisories/new), or
2. Contact the maintainer through the repository issue tracker with the subject line `Security:` and avoid posting exploit details publicly until a fix is available.

Include steps to reproduce, affected versions, and impact if known.

## Response

We aim to acknowledge reports within 7 days and provide a remediation plan or fix timeline when possible.
