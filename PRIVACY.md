# MarkDrive Privacy Policy

Effective date: May 19, 2026

MarkDrive is a Chrome extension for editing Markdown files in Google Drive.

## Data MarkDrive Handles

MarkDrive may access:

- Markdown files you open or save through Google Drive.
- File metadata needed to show names, folders, modified times, and recent files.
- Images you paste or drop into the editor when you choose to upload them to Drive.
- Local settings such as theme, autosave interval, soft wrap, Vim mode, onboarding state, and last used folder.
- Local offline save drafts while Chrome is offline or Drive is temporarily unavailable.

## How Data Is Used

File content and uploaded images are sent to Google Drive APIs only to perform the action you requested: open, save, create, rename, trash, or upload. Settings, recent file metadata, and offline drafts are stored locally in Chrome extension storage.

## Data Sharing

MarkDrive does not sell data, serve ads, track browsing for advertising, or send document content to analytics services. Data is shared with Google Drive APIs only as required for Drive editing features.

## Data Retention

Local settings and recent file metadata remain in Chrome extension storage until you change settings, clear extension data, or uninstall the extension. Offline drafts are removed after they sync successfully.

## User Control

You can revoke MarkDrive's Google account access from your Google Account permissions page. You can remove local extension data by uninstalling MarkDrive or clearing extension storage through Chrome.

## Contact

For privacy questions or support, open an issue at [github.com/chayprabs/drive-md-editor](https://github.com/chayprabs/drive-md-editor/issues) or use the Chrome Web Store support channel when published.
