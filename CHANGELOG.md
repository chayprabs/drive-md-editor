# Changelog

## 1.0.0 - 2026-05-19

Initial MarkDrive release.

### Added

- Chrome MV3 extension for editing Google Drive Markdown files.
- Drive open, save, create, rename, trash, folder browsing, breadcrumbs, and context menu integration.
- Split Markdown editor and preview with task lists, tables, footnotes, anchors, callouts, Mermaid, KaTeX, and syntax highlighting.
- CodeMirror editor with line numbers, folding, formatting actions, Vim mode, find and replace, image paste upload, and HTML paste conversion.
- Autosave, manual save, offline queue retry, conflict comparison, and Drive error recovery.
- Recent files, onboarding, full settings page, themes, export to Markdown, HTML, and print-ready PDF.
- Chrome Web Store listing, privacy policy, icons, Open Graph image, bundle budget, and extension validation gates.
